Free · no account · data stays on your phone

How to install

  1. Tap Download for Android. If Chrome asks, tap Download anyway.
  2. Open the downloaded file (from the notification, or Files → Downloads → Workout.apk).
  3. If asked, allow Install unknown apps for Chrome / Files, then go back.
  4. Tap Install. If Play Protect warns about an unknown app, tap More details → Install anyway.

Updating

Come back here, download again and install over the old one. Your plans and workouts are kept. (Uninstalling deletes them, so use Plans → Settings → Export backup first if you ever uninstall.)

On an iPhone? This file won't work there. Use the web app instead: open it in Safari → Share → Add to Home Screen.
